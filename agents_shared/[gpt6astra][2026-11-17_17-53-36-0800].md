## Implemented scope

- `WallpaperProbe.swift`: strict schedule/argument validation; non-GUI `--validate`; default 120-second cap plus explicit finite `--sustained` mode capped at 3,600 seconds; schema-2 `CLOCK_MONOTONIC` records; actual phase-start timestamps; independent pause reasons and session-known state. Unknown initial session state conservatively blocks playback. Session inactivity is not labelled as lock detection.
- `system_metrics.py` / `measure.py`: bounded non-root process/GPU/`top MEM` samplers, per-sampler time intervals, process identity guards before CPU deltas and footprint association, incremental JSONL reads, artifact/source hashes, power context, finite run deadlines, cancellation and owned-process cleanup. RSS and rounded footprint remain separate. Missing/error data remain explicit.
- `summarize_v2.py` / dispatcher: retain only intervals wholly inside warmed, guarded actual phase windows; preserve GPU device identity; report missing footprint/identity/counter data accurately. Schema-1 summaries retain compatibility. Whole-run acceptance stays inconclusive because this summary does not implement the complete repeated protocol, helper attribution, or calibration.
- `sanitize_results.py`: anonymize schema-2 PIDs and process start identities while retaining restart distinctions; publish a reviewed numeric-preserving copy.
- `pipeline/attempt.py`, `bundle.py`, `png.py`: cancellation/publication serialization and source PNG color-contract validation, described below.
- Tests and benchmark guide updated. README, plan, agent entry points, and shared status now reflect actual code and outstanding gates. A canonical skill is being prepared under `skills/td-wallpaper/`; its packaging and dry-run review are reported in a subsequent skill checkpoint.

## Confirmed findings and disposition

| Finding | Impact | Disposition |
| --- | --- | --- |
| Cancellation during final validation could leave a published bundle while the attempt was failed | Incorrect completion/publication contract | Fixed using a per-attempt cross-process lock shared by state changes, cancellation, and publication; handled exceptions roll back directory/state. Regression cases include cancel during validation, concurrent locking, and interrupted publication. |
| Consistently sRGB-tagged source PNGs could pass a BT.709-transfer contract | Correct output tags could conceal incorrect input interpretation | Reject known conflicting/unsupported PNG color metadata, including sRGB and incompatible gamma/ICC/cICP/chromaticities. A real tiny PNG regression checks rejection. Untagged source still needs renderer/color-chart evidence. |
| Initial summary assumptions did not match actual event names, phase-start semantics, and null memory | Incorrect lifecycle counts/windows or a summary exception | Independent review found these during development; fixed with tests for actual session names, delayed phase-event emission, and unavailable footprint. Probe-config type validation also hardened. |

Publication rollback handles ordinary exceptions/interrupts; it is not a crash-safe transaction across directory and state files under SIGKILL/power loss. External `cancel` prevents publication but does not terminate an already-running encoder immediately. Alpha handling and real TD color interpretation remain separate known limitations, documented in the pipeline guide.

## Verification actually run

The current Swift source compiled with `xcrun swiftc -O`, AppKit, AVFoundation, and CoreGraphics. The full Python unittest suite passed: **90 tests, zero skips, 5.879 seconds**, using Python 3.9.6, FFmpeg/ffprobe on PATH, and `WALLPAPER_PROBE_BINARY` pointing to the compiled probe. Coverage includes option parsing without GUI launch, phase/identity/missing-data behavior, SIGTERM cleanup, schema-1 summary compatibility, source-color rejection, and cancellation/publication failures. These checks do not simulate actual lock/sleep behavior.

Reproduction from the repository root, after compiling the probe and making FFmpeg/ffprobe available:

```sh
PYTHONDONTWRITEBYTECODE=1 \
WALLPAPER_PROBE_BINARY="$PWD/research/benchmarks/build/WallpaperProbe" \
python3 -m unittest discover -s tests -v

python3 research/benchmarks/measure.py --capabilities

python3 research/benchmarks/measure.py \
  --probe research/benchmarks/build/WallpaperProbe \
  --video /path/to/synthetic-bundle/loop.mp4 \
  --output-dir research/benchmarks/results_private/new-batch/smoke \
  --schedule idle:4,play:8,cover:4,uncover:6,pause:4,idle:4 \
  --cover --pause-on-occlusion --purpose smoke --warmup-seconds 1
```

The actual smoke used the existing 720p24/480-frame synthetic M3 fixture, SHA-256 `beb17016cc013582f81ecd4b3dd5c542fd8dad44638fe3d2cf6c56ef57308b4b`. The compiled probe hash is `43b9c35d5a53ed2558ebe0f4500e23335165d4ee14c4643756e7c5586768f9c5`. Both commands ran as the ordinary user; sandbox access was approved for system/process observation. No sudo, privileged helper, lock action, TD launch, or wallpaper-setting change was used.

The capability check read one GPU device, 25 selected processes, and 25 footprint rows without errors. The smoke exited normally after 30.075 seconds with `schedule_complete` and empty error logs. Media time advanced, occlusion paused playback, visibility recovery resumed it, and scheduled pause stopped it. No completed loop, session transition, display sleep, or actual lock was observed.

**Limitations that prevent acceptance:** the machine was on battery; the probe has no product battery policy. Ambient activity occluded the desktop around 7.81 seconds, before the scheduled cover around 12 seconds. Only 2/5 retained play samples were visible, versus 3/3 uncover samples; these observations cannot establish continuous full-visibility playback cost. Three raw footprint snapshots yielded 80 identity-checked numeric rows, but none fit inside retained phase windows, so every phase's footprint remains unavailable. Fifteen sampler calls averaged 0.288 seconds wall latency (maximum 1.118); this is not CPU overhead calibration. No attribution or stable-baseline claim follows from an empty activity watchlist.

Reviewed public evidence: [provenance and limitations](../research/benchmarks/results/m1-2026-11-17/SANITIZATION.md), [summary](../research/benchmarks/results/m1-2026-11-17/summary.json), and [metadata](../research/benchmarks/results/m1-2026-11-17/smoke/metadata.json). An independent read-only pass checked all six phase windows and reported CPU/memory/GPU values against raw records, including the absence of aligned footprint samples. The original four pilot result files were not regenerated.
