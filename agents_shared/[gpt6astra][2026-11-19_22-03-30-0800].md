- Native local bundle import with hash/profile/completion checks, app-owned
  storage, muted video/cover presentation, selected screen, independent pause
  reasons, 30-second long-pause release, menu-bar controls and saved selection.
- On-demand serial creation through the calibrated `soft_gradient` template,
  with prepare/export/finalize/import stages, cancellation and preserved logs.
  The app bundles a hashed authoring kit and copies it into its own versioned
  writable workspace only when creation/editing is requested.
- Editable TD template copies. Opening refuses to displace an already running
  TD session. Modified/new artwork needs its own validation/calibration.
- Anthropic Messages and OpenAI-compatible Chat Completions adapters. The app
  sends the brief plus bounded shipped skill/job/shader/calibration context and
  accepts clarification, supported gradient parameters, or an explicit request
  for a new template. It does not execute arbitrary model-generated code.
- Origin-bound Keychain credential profiles and literal parsing of an explicitly
  selected `.env`; secrets do not enter asset packages or subprocess environments.
- Optional Open-Meteo LA weather and bounded custom HTTPS JSON mappings to a
  constrained native gradient/cloud/precipitation scene. These modes require
  neither TD nor a model request for updates. No device-location access is used.
- Updated agent skill and docs distinguish supported app operations from coding
  agents creating a genuinely new TD template. Build/use instructions are in
  [`app/README.md`](../app/README.md).

## Review findings and disposition

Independent delegated review identified and verified two coordinator fixes:

1. **P2: menu import could overwrite a generation task and clear its busy flag.**
   All imports now reserve the operation synchronously before yielding; a busy
   menu/async import is refused. Cancellation/quit retains the original owner.
2. **P2: a queued display callback could recreate a scene after stop.** An active
   generation guard rejects stale callbacks before creating a window. A regression
   posts a display notification with an absent screen, stops, drains callbacks,
   and confirms the stopped state without creating an actual window.

Other implementation corrections included preserving custom-data retry/cache
deadlines across pause/wake, keeping cache expiry independent of long Retry-After,
using current lifecycle reasons at scene start, preventing weather subscribers
from updating another scene mode, and recognizing only explicit macOS path aliases
while rejecting arbitrary import symlinks. All nine asset-library tests passed.

Cancellation escalates TERM to KILL after a 15-second grace period, then waits for
confirmed worker exit. An OS process stuck in an uninterruptible kernel wait has
no universal completion deadline. Quit waits up to 60 seconds and refuses to
finish if cleanup is still pending; we deliberately preserve ownership rather
than clear busy state while an unresolved worker might remain. Ordinary timeout,
output-limit and cancellation fixtures passed; no kernel-stuck condition was
fabricated or claimed tested.
